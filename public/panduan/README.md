# 📚 Panduan Operasional Sistem Solo Technopark (Sintesa)
## Direktori Resmi Pedoman Pengguna Multi-Peran (Multi-Role User Manuals)

Direktori ini berisi seluruh panduan operasional resmi sistem **Sintesa (Solo Technopark)** yang terbagi secara spesifik untuk masing-masing peran, mulai dari Pimpinan Eksekutif BLUD, Administrator Teknis, Tenaga Pengajar/Instruktur, Startup Binaan, Alumni Lulusan, Mitra Industri, hingga Masyarakat Umum.

Setiap panduan tersedia dalam **dua format**:
- **Format Markdown (`.md`)**: Untuk dibaca langsung di browser atau portal internal.
- **Format PDF Resmi (`.pdf`)**: Berstandar dokumen dinas A4 lengkap dengan **Logo Resmi Solo Technopark**, header BLUD, penomoran halaman otomatis, dan footer keabsahan sistem.
